
| Endung    | Singular                            | Plural         |
| --------- | ----------------------------------- | -------------- |
| Vokal     | el amigo                            | los amig       |
|           | El restarunte                       |                |
|           | El hotel                            | Los Ho         |
|           | la discoteca                        | las disco      |
|           | la amiga                            | las            |
|           | el instituto                        | los ins     os |
|           | la caftetaria                       | las ca     ias |
| Konsonant | El restaurante                      | los r     ntes |
|           | El hotel                            | s              |
|           | La un Las unviersidades  cersidades |                |

Regel die Meisten Weiblichen Substantive enden auf **-a**
Die Meisten männlichen Substantive enden auf **-o**
Wen das substantive auf ein **Vokal** endet, wird *im Plural* nur ein **-s angehängt**
Wenn das das substantive auf einen Konsunaten endet, wird *im Plural ein* **es** angehängt
