# Vor dem Komma
Um vom dezimal zum Binär system umzurechnen wird durch zwei geteilt. Und der rest von den Rechnungen wird dann als Lösung genommen (siehe Bsp. 1 & Bsp. 2)
## Beispiel 1
15 : 2 =  7  Rest: 1    
7 : 2 =    3  Rest: 1     
3 : 2 =    1  Rest: 1   
1 : 2 =    0  Rest: 1

Resultat: 1111
## Beispiel 2

16:2 = 8 Rest: 0
  8:2 = 4 Rest: 0 
  4:2 = 2 Rest: 0 
  2:2 = 1 Rest: 0 
  1:2 = 0 Rest 1

Resultat; 10000

**Es wird immer durch 2 geteilt bis du am ende 1:2 teilen musst.**
# Nach dem Komma 
Die zahl wird immer * 2 genommen bis das Ergebnis 0 oder 1 ist (siehe bsp. 1). Oder bis sich die anfangs zahl wieder holt. (siehe bsp. 2)

## Bsp. 1

 2 · 0,5 = 1    --> Ziffer: 1

Resultat: 0,1 

## Bsp. 2 

2 · 0,4 = 0,8    --> Ziffer: 0
2 · 0,8 = 1,6    --> Ziffer: 1
2 · 0,6 = 1,2    --> Ziffer: 1
2 · 0,2 = 0,4    --> Ziffer: 0
2 · 0,4 = 0,8    --> Ziffer: 0  *--wird weggelassen*

Das **wiederholende** Ergebnis 0,8 trat im 1. Schritt schon auf ab da wiederholt sich die Nachkommaziffer periodisch. Wenn sich die letzte Rechnung wiederholt dann lässt man den letzten rest aus.:

0110  0110
0110  0110
0110  0110
...
