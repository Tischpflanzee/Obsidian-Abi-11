# 4


- PC-Computer: Meist zur Nutzung von einem User um ein  betriebssystem laufen zu lassen mit grafischer oberfläche.(Linux, Mac, Windows, Solaris ?, AmigaOS? )
- Wird Benutz von den meisten Menschen benutz die ein Betiebsystem benutzen wollen, um damit programme auszuführen -> office Programme, Spiele usw.
- 




- Server: Meist zur nutzung für: Webseiten hosten, Datei Server bsp.: google Drive, oder auch Mail-Server.
- Von Konzernen oder Privatpersonen die beispielsweise eine Webseite hosten wollen.
- Eingabe/Ausgabe möglichkeiten: Meist wenniger Eingabe  und Ausgabe möglichkeiten als bei einem PC da sie nicht nötig sind
- Meist hoher Arbeitsspeicher, und viel cpu leistung mit einer hohen zuverlässigkeit.
- 



-  Eingebettete Rechner: chipkarten(RMV-Karte), Kaffemaschiene -> eingabe -> Durchführung vom Eingebetteten system -> Ausgabe Kaffe.
